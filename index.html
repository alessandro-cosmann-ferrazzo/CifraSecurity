Operação

A chave embaralha o estado interno. O texto só se combina com o fluxo gerado por essa chave, por XOR.

Lógica da cifra

Informe uma mensagem e uma chave para ver o fluxo byte a byte.

  1. KSA A chave percorre o vetor S, de 0 a 255, e troca posições. Ela não é gravada no texto cifrado.
  2. PRGA O estado embaralhado produz o fluxo Z, um byte para cada byte da mensagem.
  3. XOR Cifrar: C = P ⊕ Z. Decifrar: P = C ⊕ Z. A mesma chave recria o mesmo Z.

Limitações

  • O RC4 está proibido em TLS desde a RFC 7465, de 2015.
  • A mesma chave gera o mesmo fluxo. Duas mensagens cifradas com ela revelam P₁ ⊕ P₂.
  • O embaralhamento inicial tem viés estatístico. Isso sustenta ataques como o FMS.
  • Esta página demonstra o algoritmo. Ela não serve para proteger dados reais.
